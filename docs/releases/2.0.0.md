Every flow now runs on one common path from request to handover, the skill scripts run on Python instead of PowerShell, and releases get a dev-to-main cycle with pre-releases.

- **Breaking — one common path:** every flow walks Request → Design → Plan → build iterations → Approval → Handover, and each ends with the result approved. Approvals are recorded from the user's own words.
- **Breaking — renames:** the Spec-driven flow is now Spec, the approval gates are renamed, and `an-dr-dev-integrate` needs `--wip-data-skill`.
- **Breaking — Python scripts:** every skill script and test runner is Python; the `.ps1` scripts are gone, so call them as `python <script>.py`. Python 3 replaces PowerShell 7 as the prerequisite.
- **Vibe ends with handover:** Vibe no longer lands its branch; integration happens only when you ask for it.
- **DO-NOT-MERGE commits:** workflow state travels in one `DO-NOT-MERGE:` commit at the branch tip, which integration drops; integration refuses a branch with a revert or a tmp file in a commit that lands.
- **Release cycle:** amendments land on `dev`, `main` moves only by tested fast-forward promotion, and pre-releases are tagged `v<version>-pre.<n>` and published as GitHub pre-releases. Pull requests target `dev`; see `CONTRIBUTING.md`.
