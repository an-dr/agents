The first versioned release of the agents process: the engineering policy and its skills, packaged as one zip.

- **Package:** `agents-1.0.0.zip` holds `AGENTS.md`, `README.md`, `VERSION`, `LICENSE`, and every skill except those under `skills/_repository`, which only maintain this repository. `SHA256SUMS` lists its checksum.
- **Flows:** Vibe, Spec-driven, and Supervised, each started through the workflow controller, with stages, gates, and a handoff kept in `tmp-agent-wip.json` and shown on a live progress page.
- **Work-in-progress data:** `an-dr-ai-use-wip-data` is the one way to read and write `tmp-agent-wip.json`, with a strict register of sections, owners, fields, and readers.
- **Integration onto any base:** a branch lands on the branch it started from, `dev` as well as `main`, and every `tmp-` file is stripped from its history on the way.
