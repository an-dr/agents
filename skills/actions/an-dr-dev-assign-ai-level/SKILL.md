# Assign AI level

Defers: level definitions to `an-dr-convention-ai-level`; questions to `an-dr-ai-use-user-interface`.

## Ask

1. Look in the README for an existing AI Level badge.
2. Ask a direct yes/no question whether to assign an ai-level.dev level; with an existing badge, ask whether to keep or reassess it. Announcing that the offer is ready is not the question.
3. On no, change nothing and do not ask again this session.

## Assess

1. Scan for AI signals: commit or pull-request text naming an AI tool, comments such as `generated by` or `AI-assisted`, agent instruction files, uniform style across unrelated modules, documentation outweighing code.
2. Check your own past sessions on the project, when any, for what they created or changed: docs, tests, functional code, architecture; this is the most direct evidence.
3. Choose by the highest involvement found:

| Highest involvement                                                                         | Level |
| ------------------------------------------------------------------------------------------- | ----- |
| no signal                                                                                   | 0     |
| docs, comments, or commit messages only                                                     | 1     |
| tests, configs, or assets, not functional code                                              | 2     |
| functional code, with review visible in small commits, mixed authorship, or review comments | 3     |
| core logic or architecture, little sign of review                                           | 4     |

4. Propose one level with its signals and what could not be seen; absence of a signal is not proof of AI-free work.
5. Ask the user to confirm or pick another, with the five levels as options and the proposal first.

## Assign

1. Print the badge for the confirmed level:

```powershell
pwsh <skill>/scripts/new-badge.ps1 -Level <0-4> [-Style standard|compact]
```

Rejects a level outside 0 to 4; prints the badge as Markdown and HTML, `[![AI Level N](https://ai-level.dev/badge/standard/N.svg)](https://ai-level.dev/level-N)`; `compact` replaces `standard` in the image URL.

2. Place the Markdown form with the README's other badges, replacing an old AI Level badge; a README with no badge line gets one only after the user agrees to the placement.
3. Check the README with the Markdown convention.

## Output

- Level, its evidence, and the file and line of the badge.
- HTML form when the README is not Markdown.

## Rules

- Assign nothing before the user says yes.
- The user's confirmed level is final; a level below the evidence is reported as such.
- Every cited signal exists in the repository or the session history.
