# Assign AI level

Disclosing AI usage is the owner's choice, so this skill asks first and assigns only on a yes. The levels belong to `an-dr-convention-ai-level`; this skill assesses the repository against them, confirms the result, and places the badge.

## Ask

Ask through `an-dr-ai-send-message` whether the user wants an ai-level.dev level assigned to this repository, with the options yes and no. Look in the README for an existing AI Level badge first and, when one exists, ask whether to keep or reassess it. On no, change nothing and do not ask again in the same session.

## Assess

The level is a claim about the repository, so it rests on evidence.

- **Scan.** Look for AI signals: commit or pull-request text naming an AI tool, comments such as `generated by` or `AI-assisted`, instruction files for agents, uniform style across unrelated modules, and documentation that outweighs the code.
- **Use session history.** When you have your own past sessions on the project, check what they created or changed: documentation, tests, functional code, or architecture. This is the most direct evidence.
- **Choose by the highest involvement found.** Level 0 when no signal exists. Level 1 when AI appears only in docs, comments, or commit messages. Level 2 when it reaches tests, configs, or assets but not functional code. Level 3 when it wrote functional code and review shows, in small commits, mixed authorship, or review comments. Level 4 when core logic or architecture is AI-generated with little sign of review.
- **State the evidence.** Propose one level with the signals behind it and what could not be seen. Absence of a signal is not proof of AI-free work.

Ask the user to confirm the level or pick another, as an `an-dr-ai-send-message` question with the five levels as options and the proposal first.

## Assign

Print the badge for the confirmed level and place the Markdown form with the README's other badges, replacing an old AI Level badge. Add no badge line to a README that has none without the user's agreement to the placement. Check the README with the Markdown convention afterwards.

```powershell
pwsh <skill>/scripts/new-badge.ps1 -Level <0-4> [-Style standard|compact]
```

The script rejects a level outside 0 to 4 and prints the badge as Markdown and as HTML, in the form `[![AI Level N](https://ai-level.dev/badge/standard/N.svg)](https://ai-level.dev/level-N)`. The `compact` style replaces `standard` in the image URL.

## Output

Report the level, the evidence behind it, and the file and line where the badge now sits. Give the HTML form when the user's README is not Markdown.

## Rules

- **Ask first.** Assign nothing before the user says yes.
- **Owner decides.** The user's confirmed level is final, and a level below the evidence is reported as such.
- **No invention.** Every signal cited exists in the repository or the session history.
