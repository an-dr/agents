# Priorities

Ordered by consequence, not ease of fix.

| Priority      | Meaning                                                                                        | Level      |
| ------------- | ---------------------------------------------------------------------------------------------- | ---------- |
| P0 — critical | demonstrated wrong results, data loss, security exposure, or a contradiction blocking safe use | `critical` |
| P1 — high     | confirmed problem with substantial user or maintenance cost, to fix soon                       | `high`     |
| P2 — normal   | local inconsistency, avoidable complexity, or documentation defect with a concrete cost        | `notice`   |
| P3 — low      | small clarity improvement with an explained benefit                                            | `notice`   |

- Questions stay at P2 or P3; state any potentially larger consequence separately.
- Priority measures urgency; the basis label measures certainty.
