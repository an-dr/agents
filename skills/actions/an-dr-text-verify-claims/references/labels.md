# Kinds and verdicts

## Kind

| Kind          | Means                                                                      |
| ------------- | -------------------------------------------------------------------------- |
| `observed`    | Stated directly by a source: a value, a quote, a line of code              |
| `derived`     | Computed from sources: a total, a ratio, a trend, a count                  |
| `inference`   | Interpretation beyond the data: cause, intent, explanation, generalisation |
| `assumption`  | An unstated premise another claim depends on, written out explicitly       |
| `opinion`     | A value judgment: good, risky, should, the best                            |
| `speculation` | A prediction or hypothetical: will, likely, could                          |

## Verdict

| Verdict        | Means                                                                                          |
| -------------- | ---------------------------------------------------------------------------------------------- |
| `supported`    | The cited evidence states or entails it                                                        |
| `partial`      | True only with a qualification the text drops: narrower scope, different period, softer degree |
| `contradicted` | The evidence says otherwise                                                                    |
| `not-found`    | The evidence set has nothing on it                                                             |
| `unverifiable` | No evidence can settle it, as with opinion and speculation                                     |
