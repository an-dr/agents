# Evaluation intent

Preserve these task-specific outcomes and regression boundaries:

- **BASE-001.** A new project gets use cases in the convention's format and an architecture derived from them, with no low-level design.
- **SCOPE-EXISTING.** A small change to an existing feature does not get a specification unless the user asks.
- **SCOPE-UNCLEAR.** Work that may or may not be new produces a question to the user, not a guess.

The discovery cases reuse the first task with implicit and noisy phrasing so activation can be compared separately from execution. Existing case IDs and their evidence remain stable.

Prefer the declared isolated environment. If only isolation controls are unavailable, use the testing convention's best-effort protocol and report security or discovery limits separately. Keep expected behavior and assertions private.
