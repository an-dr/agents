# Evaluation intent

Preserve these task-specific outcomes and regression boundaries:

- **BASE-001.** The pipeline comes from the repository's real commands, and nothing is published or claimed as proven without a platform run.

The discovery cases reuse the first task with implicit and noisy phrasing so activation can be compared separately from execution. The negative case checks that a nearby question does not load the target or create unsolicited artifacts. Existing case IDs and their evidence remain stable.

Prefer the declared isolated environment. If only isolation controls are unavailable, use the testing convention's best-effort protocol and report security or discovery limits separately. Keep expected behavior and assertions private.
