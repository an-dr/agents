# STM32 CubeMX layout

The layout of STM32 firmware generated by STM32CubeMX for CMake, added to the shared rules in [the convention core](../SKILL.md). The project's own code follows the component layout in [cpp.md](cpp.md). PlatformIO firmware is laid out by [platformio.md](platformio.md).

## Generated part

- **Source of truth.** `<project>.ioc` at the root is the source of every generated file.
- **Where CubeMX writes.** Generated code stays where CubeMX puts it: `Core/`, `Drivers/`, `Middlewares/`, the startup `.s` and linker `.ld` files at the root, and `cmake/stm32cubemx/` with the toolchain file in `cmake/`.
- **Committed.** Generated files, `Drivers/` included, are committed, so the project builds without CubeMX installed.
- **Changed only by regeneration.** Generated files change through the `.ioc` and regeneration, and by hand only inside their `USER CODE BEGIN` and `USER CODE END` blocks. Those blocks hold only calls into the project's components.

## Project code

- **Components.** The project's own code is in `components/<name>/`, outside the generated folders, so regeneration never touches it.
- **Hardware interface.** `components/hal-interface/` declares what the application needs from the hardware; `components/hal-stm32/` implements it with the Cube HAL; `components/app/` holds the application logic and depends only on the interface.
- **Host build.** `components/hal-host/` implements the interface for the development machine, so the application logic builds and runs there.
- **Build.** The root `CMakeLists.txt` and `CMakePresets.json` are written once by CubeMX and then extended to add the components; regeneration rewrites only `cmake/stm32cubemx/`.

## Tests

Tests in `tests/` build for the development machine against `hal-host` and need no board.

## Examples

```text
<project>.ioc  CMakeLists.txt  CMakePresets.json  startup_stm32f103xb.s  STM32F103XX_FLASH.ld
cmake/                 gcc-arm-none-eabi.cmake  stm32cubemx/
Core/  Drivers/  Middlewares/    generated
components/hal-interface/  hal-stm32/  hal-host/  app/
tests/unit/app/
```
