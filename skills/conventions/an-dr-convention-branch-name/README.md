# an-dr-convention-branch-name

How a work branch is named: the repository's own style when it has one, otherwise Conventional Branch.

## When it runs

A convention is read, never run. Skills load it when they create, name, or review a branch.

## How it works

- **The repository's style first.** When its existing branches or contributing documents show a clear naming rule, that rule wins.
- **Conventional Branch otherwise.** `<type>/<description>`: a type such as `feature`, `fix`, or `chore`, then a short lowercase description with hyphens between words, like `feature/add-login-page`.

## What you get

Branch names that match the repository they live in, and a predictable default where it has no rule.
