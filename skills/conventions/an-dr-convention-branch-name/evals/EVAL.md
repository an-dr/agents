# Evaluation intent

Preserve these task-specific outcomes and regression boundaries:

- **BASE-001.** A repository with a clear branch style keeps it.
- **BASE-002.** A repository without one gets a Conventional Branch name.

The discovery cases reuse the second task with implicit and contextual phrasing so activation can be compared separately from execution. The negative case checks that a nearby request does not load the target or create unsolicited artifacts. Existing case IDs and their evidence remain stable.

Prefer the declared isolated environment. If only isolation controls are unavailable, use the testing convention's best-effort protocol and report security or discovery limits separately. Keep expected behavior and assertions private.
