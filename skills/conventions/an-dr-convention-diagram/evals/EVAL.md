- **BASE-001.** An over-budget diagram with a nested group becomes an overview with a black-box node plus a separate diagram for the group's inside, each within the budget, with explanations moved from the arrows into prose.

The discovery cases reuse the first task with implicit and noisy phrasing so activation can be compared separately from execution. The negative case checks that a nearby question does not load the convention or create unsolicited artifacts. Existing case IDs and their evidence remain stable.

Prefer the declared isolated environment. If only isolation controls are unavailable, use the testing convention's best-effort protocol and report security or discovery limits separately. Keep expected behavior and assertions private.
